# Komponen Post-IT

Storybook ini berisi semua komponen UI yang digunakan di aplikasi. Komponen dikelompokkan sebagai berikut:

## Components / Atoms
Building block dasar: **Label**, **Iconify**, **TextMaxLine**, **SvgColor**, **RouterLink**.

## Components / Data Display
Menampilkan data & konten: **EmptyContent**, **SearchNotFound**, **Table** (TableNoData, TableSkeleton, TableHeadCustom, TableEmptyRows, TablePaginationCustom, TableSelectedAction), **Chart**, **FileThumbnail**, **DownloadButton**, **Image**, **Markdown**.

## Components / Feedback
Status & loading: **LoadingScreen**, **SplashScreen**, **StatusCheck**, **DevModeBanner**.

## Components / Inputs
Form & upload: **Upload** (Upload, UploadBox, UploadAvatar, PreviewSingleFile, RejectionFiles), **HookForm** (RHFTextField, FormProvider), **TransferList** (SimpleTransferList).

## Components / Navigation
Navigasi: **CustomBreadcrumbs**, **NavSectionVertical**.

## Components / Overlay
Dialog & popover: **ConfirmDialog**, **CustomPopover**.

## Components / Layout
Layout: **Scrollbar**.

## Components / MFA
Multi-Factor Auth: **OTPForm**, **QRCode**.

## Components / Media
Media & branding: **Image**, **Logo**, **Markdown**, **FileThumbnail**.

## Components / Animate
Animasi: **MotionContainer**.

---
